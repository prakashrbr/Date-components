4. Actual Date & Time

An Actual Date & Time picker allows users to record the exact date and time when a clinical event actually occurred.

Goal: Make timestamp entry fast, accurate, and clinically consistent.

Examples: Discharge, admission, medication administration, specimen collection, procedure, or clinical observation.

When To Use

  • When recording an event that has already occurred.
  • When the exact date and time are clinically relevant.
  • When the timestamp needs to be compared with other clinical events.

When Not To Use

  • Known Date → when only a date is required.
  • Calendar Date Picker → when selecting a date without a specific time.
  • Available Date & Time → when scheduling a future event.
  • Date & Time Range → when recording a start and end time.
Use Actual Date & Time when the exact moment an event occurred matters.

Input Rules

  • Allow direct entry of date and time.
  • Allow calendar selection for the date.
  • Clearly label Date and Time.
  • Follow the configured locale and time format.
  • Prefer 24-hour time where appropriate.
  • Show the timezone when it is relevant.

Behavior

  • Allow users to enter and edit date and time independently.
  • Provide Now as a quick action when appropriate.
  • Keep focus and interaction predictable.
  • Allow users to correct the recorded time.
  • Do not automatically use the documentation time as the event time.
Documentation time and event time should not be assumed to be the same.

Smart Behavior

Use clinical context to:

  • Suggest Today or Now when appropriate.
  • Validate the timestamp against related events.
  • Identify timeline conflicts.
  • Apply relevant date/time restrictions.
  • Distinguish the event time from the time it was documented.

Validation & Constraints

  • Prevent future dates and times by default.
  • Support minimum and maximum date/time boundaries.
  • Validate against related clinical events.
  • Identify impossible sequences.

Anatomy

Callouts are measured from the rendered component, so they follow each design system's layout.

  1. Date & time field – Separate date and time parts, each typed or picked.
  2. Quick actions – Now fills the current date and time; Calendar, Today and Yesterday set the date.
  3. Month / year navigation – Moves between months; the title opens the year list.
  4. Weekday header – Days of the week, starting on Monday.
  5. Calendar grid – Future dates are greyed out and can't be picked.
  6. Time entry – Type hh:mm and choose AM or PM.
  7. Actions – Cancel discards changes; Done records the date and time.
Dates Legend

States

Field states. Focus outlines only the part being edited; the open state outlines the whole field.

Validation

Future times are blocked by default, and the time is checked against related clinical events.

Use Along With Buttons

  • Now populates the current date and time into the input.
  • The date and time remain editable after using Now.
  • Now becomes disabled once the current timestamp is selected.
  • If the user changes the date or time, Now becomes available again.
  • Use Now only when the current time accurately represents the event time.
